# Biblioteca local de imagens

Coloque aqui imagens próprias ou previamente autorizadas para o Zuno reutilizar nos vídeos.

Formatos aceitos nesta fase:

- `.png`
- `.jpg`
- `.jpeg`

Opcionalmente crie um `manifest.json` nesta pasta para informar tags, emoção, tema, origem e licença de cada arquivo. Sem manifesto, o Zuno ainda consegue listar as imagens, mas assume origem local do usuário.

Consulte `docs/visual-asset-resolver.md` para o formato completo.

# Prova local do Product e Site Engine

Capturas de desktop e celular usando apenas dados fictícios. Os testes exercitam API/JWT, banco, catálogo, estoque, oportunidades, publicação, domínio e upload.

- 388 testes backend aprovados, em 41 arquivos; 32 cenários novos.
- 123 testes frontend aprovados.
- 16 cenários de navegador aprovados, sem retries.
- Build, tipos, 49 contratos e isolamento arquitetural aprovados.

Dados e capturas: [validation.json](validation.json). Relatório: [product-site-engine-validation.md](../../product-site-engine-validation.md).

A fixture usa uma imagem PNG mínima para testar upload e persistência; os espaços claros nas galerias não são imagens reais de produtos. Nenhum servidor de produção foi alterado.

# Fontes gratuitas configuradas

Esta pasta prepara o Zuno para provedores gratuitos de imagens usados por manifesto.

Nesta fase não há chamada direta para Pexels, Pixabay ou Unsplash. Para usar imagens externas, cadastre um `manifest.json` com origem, autor, licença e URL de download quando aplicável.

As imagens baixadas automaticamente ficam no cache local `assets/visual/.cache`.

Consulte `docs/visual-asset-resolver.md` para o formato completo.
